## ARTIFICIAL INTELLIGENCE RESEARCH

My research focuses on making intelligent systems safer, more capable, measurable, and reliable.

### 01. Self-Editing AI Agents (SEAA)

**LLM Safety via Inference-Time Rewriting**

<sub>2025 · Independent Research · First Author · Preprint</sub>

A lightweight inference-time safety framework designed to inspect and rewrite potentially harmful LLM outputs without modifying underlying model parameters.

**Research contributions**

- Designed a reasoning-trace inspection and adaptive rewriting pipeline.
- Implemented output inspection and safety evaluation.
- Evaluated harmful-output reduction and false-positive behaviour.
- Reported a 20% reduction in harmful outputs with zero false positives on safe prompts.
- Developed StudentSafetyBench-50, a 10-category student-domain LLM safety benchmark.

**Pipeline**

```text
USER INPUT
    |
    v
LANGUAGE MODEL
    |
    v
OUTPUT INSPECTION
    |
    v
SAFETY EVALUATION
    |
    +----------+
    |          |
   SAFE      UNSAFE
    |          |
    |          v
    |      ADAPTIVE REWRITING
    |          |
    +----+-----+
         |
         v
   FINAL RESPONSE
```

`LLM Safety` `Inference-Time Rewriting` `Benchmarking`

### 02. VisionRAG

**Multimodal Retrieval-Augmented Generation for Academic Document Analysis**

<sub>2026 · First Author · Under Review at JMLR</sub>

A multimodal retrieval architecture designed to understand academic documents through textual and visual representations.

**Research contributions**

- Integrated text and image encoders.
- Developed hierarchical document chunking.
- Implemented adaptive retrieval scoring.
- Evaluated 2,500 academic papers and 8,000 QA pairs.
- Reported 82.4% overall accuracy and 89.3% visual accuracy.

**Architecture**

```text
         ACADEMIC DOCUMENTS
                 |
          +------+------+
          |             |
       TEXT DATA     IMAGE DATA
          |             |
          v             v
      TEXT ENCODER   IMAGE ENCODER
          |             |
          +------+------+
                 |
          MULTIMODAL INDEX
                 |
          HYBRID RETRIEVAL
                 |
          ADAPTIVE RANKING
                 |
          CONTEXT ASSEMBLY
                 |
            LLM INFERENCE
                 |
          CITED RESPONSE
```

`Multimodal AI` `Vision-Language Models` `RAG`
